QUESTIONS

Before you
convert.

What file types can I convert? +

DocSwitch currently supports PDF, DOCX, DOC, TXT, RTF, PPTX, PPT, JPG, JPEG, PNG and WEBP as input formats.

Is there a file size limit? +

Files are currently limited to 25 MB per conversion.

Do I need an account? +

No. DocSwitch is designed to let you convert files without requiring an account.

What happens to my files? +

Files are processed for conversion and are intended to be automatically removed after processing.
